# Tip Calculator / Bill Splitter

A responsive single-screen tip calculator that updates results live while typing.

## Features

- Live calculations
- Preset tip buttons
- Custom tip
- Inline validation
- Reset functionality
- Responsive design

## Run Locally

1. Clone repository

git clone YOUR_REPO_URL

2. Open folder

3. Open index.html

Or use Live Server:

Right click index.html → Open with Live Server

No installation required.
